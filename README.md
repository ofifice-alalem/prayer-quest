# 🕌 تطبيق متتبع الصلوات اليومية (Daily Prayer Quest)
> منصة تفاعلية لتسجيل الصلوات اليومية والنوافل بأسلوب منصات الألعاب الحديثة (Steam / Gaming HUD) ولمسات هندسية إسلامية فاخرة.

## 📌 مميزات النظام
- **نظام نقاط ألعاب تفاعلي:**
  - 100 نقطة تلقائياً لكل فريضة عند إدراك تكبيرة الإحرام.
  - 80 نقطة عند إدراك جميع الركعات وفوات تكبيرة الإحرام.
  - خصم دقيق للركعات الفائتة حسب كل صلاة (الفجر، الظهر، العصر، المغرب، العشاء).
  - مسار نقاط منفصل تماماً للنوافل والسنن الرواتب.
- **واجهة مستوحاة من منصات الألعاب (Steam Gaming UI):**
  - دعم الوضعين الفاتح والداكن (الوضع الداكن: كحلي ملكي عميق مع برتقالي ناري ذهبي).
  - زخارف هندسية إسلامية مدمجة كخلفيات هادئة بتقنية SVG.
- **شاشات وتقارير احترافية:**
  - **لوحة صلوات اليوم:** تسجيل سريع وتفاعلي وحساب فوري للمستوى والشارات.
  - **التقويم الشهري:** شبكة تفاعلية مع قفل الأيام المستقبلية وقائمة جانبية منزلقة (`Side Drawer`) لعرض وتعديل صلوات الأيام السابقة.
  - **تقرير الركعات الفائتة:** إحصائية دقيقة وجدول يقتصر حصراً على الأيام التي ضاعت فيها ركعات.
  - **تقرير صلوات المسجد والنوافل:** تتبع صلوات الجماعة والسنن الرواتب.
  - **السجل العام والتصدير:** مصفوفة شهرية مع إمكانية التصدير كصورة `PNG`، ملف `PDF`، أو نسخة احتياطية `JSON`.
- **التخزين والأمان:**
  - محرك `IndexedDB` محلي فائق السرعة وبدون حدود تخزين.
  - يعمل بدون خادم وجاهز 100% للنشر على `GitHub Pages`.

## 🛠️ التقنيات المستخدمة
- **React 18**
- **Vite**
- **Tailwind CSS**
- **Lucide Icons**
- **IndexedDB**
