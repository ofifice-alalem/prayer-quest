# 🕌 تطبيق متتبع الصلوات اليومية (Daily Prayer Quest)
> منصة تفاعلية متطورة لتسجيل ومتابعة الصلوات اليومية والنوافل بأسلوب منصات الألعاب الحديثة (**Steam / HUD Gaming Style**) مع لمسات هندسية وزخرفية إسلامية أصيلة.

---

## 🎮 فكرة التطبيق وهوية التصميم
تم تصميم الموقع بواجهة مستوحاة من واجهات الألعاب الاحترافية مثل **Steam** و **Gaming Clients** لتحفيز المسلم على المحافظة على صلاة الجماعة في المسجد من تكبيرة الإحرام:
* **الوضع الداكن (Gaming Navy & Vibrant Orange):** يعتمد على الكحلي الداكن الفخم مع البرتقالي الناري المتوهج، بدون أسود قاتم.
* **الوضع الفاتح (Light Mode):** مظهر لؤلؤي ناصع مريح مع الحفاظ على هوية التميز البرتقالي.
* **زخارف إسلامية أصيلة:** شبكة هندسية إسلامية مدمجة بالخلفية بتقنية SVG عالية الدقة.

## ⚡ نظام النقاط واحتساب الركعات (Scoring Mechanics)

| الصلاة | الركعات المفروضة | تكبيرة الإحرام | نقاط كل ركعة مدركة | الإجمالي الكامل |
| :--- | :---: | :---: | :---: | :---: |
| **الفجر** | 2 | 20 نقطة | 40 نقطة / ركعة | **100 نقطة** |
| **الظهر** | 4 | 20 نقطة | 20 نقطة / ركعة | **100 نقطة** |
| **العصر** | 4 | 20 نقطة | 20 نقطة / ركعة | **100 نقطة** |
| **المغرب** | 3 | 20 نقطة | 26.67 نقطة / ركعة | **100 نقطة** |
| **العشاء** | 4 | 20 نقطة | 20 نقطة / ركعة | **100 نقطة** |

### قواعد الحساب الذكي:
1. **قاعدة تكبيرة الإحرام:** بمجرد تحديد «أدركت تكبيرة الإحرام»، يُحسب تلقائياً **100 نقطة كاملة** (لأن إدراك تكبيرة الإحرام يعني حكماً إدراك جميع الركعات في المسجد).
2. **صلاة الجماعة بدون تكبيرة الإحرام:** إذا حضرت وأدركت جميع الركعات لكن فاتتك التكبيرة الأولى، تحصل على **80 نقطة** (80%).
3. **الركعات الفائتة:** يُخصم من الـ 80 نقطة بحسب عدد الركعات الضائعة بدقة.
4. **صلوات النوافل (مسار منفصل):** 100 نقطة لكل نافلة (سنة الفجر، الضحى، الرواتب، الوتر) في مسار ونسبة منفصلة تماماً عن الفرائض.

## 📱 صفحات وأقسام التطبيق
1. **صلوات اليوم (Today's Quest):** لتسجيل الفرائض والنوافل اللحظية وحساب فوري للمستوى والشارات والتتابع اليومي (Streak).
2. **التقويم الشهري (Calendar & Side Drawer):** شبكة تقويم كلاسيكية؛ الأيام المستقبلية **مقفلة تماماً وغير قابلة للضغط**، والضغط على أي يوم ماضٍ أو اليوم الحالي يفتح **قائمة جانبية منزلقة (Side Drawer)** لعرض وتعديل الصلوات فورياً.
3. **تحليل الركعات الفائتة (Missed Rak'ahs Report):** إحصائيات دقيقة لإجمالي الركعات الفائتة في الشهر، وتوزيعها على كل صلاة، وجدول مخصص يعرض **حصراً الأيام التي ضاعت فيها ركعات** مع بيان الصلاة وعدد الركعات الضائعة.
4. **صلوات المسجد والنوافل (Mosque & Sunnah Tracker):** إحصائيات الصلوات التي صُلّيت خارج المسجد أو فاتت، وتتبع النوافل والسنن المتروكة.
5. **السجل الشهري واستوديو التصدير (Export Studio):** مصفوفة شهرية للأيام؛ علامة (`✓`) لصلاة المسجد ورقم الركعات الفائتة عند ضياعها، مع إمكانية التصدير كـ **صورة PNG عالية الدقة** أو **ملف PDF منظم**، بالإضافة إلى حفظ واسترجاع النسخ الاحتياطية.

## 💾 التخزين والأمان (IndexedDB Engine)
* يعتمد الموقع على محرك **IndexedDB** المحلي المدمج في المتصفح.
* سعة تخزين غير محدودة وسرعة فائقة بدون الحاجة إلى خادم خلفي.
* يعمل دون اتصال بالإنترنت، ويمكن تنزيل نسخة احتياطية بصيغة `JSON` بضغطة زر لنقلها لأي جهاز آخر أو حفظها في مستودع GitHub.

## 🚀 التشغيل والنشر على GitHub Pages

### التشغيل المحلي:
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء ملفات الإنتاج للنشر
npm run build
```

### تفعيل GitHub Pages على المستودع:
1. ادخل إلى مستودعك على GitHub: [github.com/ofifice-alalem/prayer-quest](https://github.com/ofifice-alalem/prayer-quest)
2. اذهب إلى **Settings** > **Pages**.
3. تحت خيار **Build and deployment** > **Source**:
   * اختر **GitHub Actions**.
4. سيتم النشر التلقائي فوراً وسيعمل الموقع أونلاين على الرابط:
   `https://ofifice-alalem.github.io/prayer-quest/`
