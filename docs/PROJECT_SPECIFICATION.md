# 🕌 وثيقة المواصفات الفنية والمعمارية لمشروع متتبع الصلوات اليومية
### (Daily Prayer Quest - Steam / Gaming Islamic Style)
**التقنيات المعتمدة:** React 18+ | Vite | Tailwind CSS | Lucide Icons | IndexedDB

---

## 1. نظرة عامة على المشروع (Project Overview)
تطبيق ويب تفاعلي متقدم مصمم كمنصة ألعاب حديثة (Steam / HUD Gaming Style) مع لمسات هندسية إسلامية أنيقة. 
يتم بناء التطبيق باستخدام **React + Vite + Tailwind CSS** ليتم تصديره عبر `npm run build` إلى ملفات ثابتة فائقة السرعة تُنشر مباشرة على **GitHub Pages**.

يهدف التطبيق إلى تعزيز المحافظة على صلاة الجماعة في المسجد من تكبيرة الإحرام، وتتبع النوافل والركعات الفائتة بإحصائيات بيانية وتقارير تفاعلية، مع إدارة دقيقة للبيانات عبر محرك `IndexedDB` المحلي وإمكانية تصدير واستيراد النسخ الاحتياطية.

---

## 2. نظام النقاط والحساب الرياضي (Scoring Mechanics)

تم تصميم النظام ليعطي وزناً حاسماً لإدراك تكبيرة الإحرام وصلاة الجماعة في المسجد:

```
                             [ الصلاة المفروضة: 100 نقطة ]
                                          |
                +-------------------------+-------------------------+
                |                                                   |
      [ تكبيرة الإحرام: 20 نقطة ]                             [ ركعات الصلاة: 80 نقطة ]
                |                                                   |
 (إذا أدركها = 100 نقطة تلقائياً)                     موزعة بحسب عدد ركعات كل فريضة:
                                                  - الفجر (2 ركعة): 40 نقطة/ركعة
                                                  - المغرب (3 ركعات): 26.66 نقطة/ركعة
                                                  - الظهر والعصر والعشاء (4 ركعات): 20 نقطة/ركعة
```

### أ. الصلوات المفروضة (500 نقطة يومياً للفرائض)
1. **قاعدة تكبيرة الإحرام الكاملة:**
   * عند تفعيل خيار **«أدركت تكبيرة الإحرام»**، تُحسب تلقائياً **100 نقطة** كاملة، ويُقفل عدّاد الركعات الفائتة تلقائياً لاعتبار الصلاة أُدركت كاملة في المسجد.
2. **قاعدة فوات تكبيرة الإحرام مع إدراك جميع الركعات:**
   * إذا صلى المسلم جميع الركعات في المسجد ولكن فاتته تكبيرة الإحرام، يحصل على **80 نقطة** (تخصم 20 نقطة).
3. **توزيع نقاط الركعات الفائتة (من أصل 80 نقطة):**
   * **صلاة الفجر (ركعتان):** كل ركعة تساوي 40 نقطة.
     * إدراك ركعة وفوات ركعة: 40 نقطة.
   * **صلاة الظهر والعصر والعشاء (4 ركعات):** كل ركعة تساوي 20 نقطة.
     * إدراك 3 ركعات (فاتت ركعة): 60 نقطة.
     * إدراك ركعتين (فاتت ركعتان): 40 نقطة.
     * إدراك ركعة (فاتت 3 ركعات): 20 نقطة.
   * **صلاة المغرب (3 ركعات):** كل ركعة تساوي 26.67 نقطة تقريباً.
     * إدراك ركعتين (فاتت ركعة): 53.33 نقطة.
     * إدراك ركعة (فاتت ركعتان): 26.67 نقطة.

### ب. صلوات النوافل (مسار نقاط مستقل تماماً)
* مسار نقاط منفصل تماماً حتى لا يختلط بمؤشر الفرائض الأساسية.
* الصلوات المشمولة (100 نقطة لكل نافلة):
  1. سنة الفجر القبلية (ركعتان).
  2. صلاة الضحى.
  3. السنن الرواتب للظهر والمغرب والعشاء.
  4. صلاة الوتر وقيام الليل.
* مؤشر مستقل لمستوى إحياء السنن (Sunnah Mastery Level).

## 3. هوية التصميم البصري (Steam Gaming & Islamic HUD)

### لوحة الألوان (Design Tokens):
* **الوضع الداكن (Gaming Navy & Vibrant Orange - الافتراضي):**
  * خلفية الواجهة الأساسية: كحلي داكن عميق فخم (`#0B132B` و `#1C2541`).
  * البطاقات والألواح العائمة: كحلي مائل للأزرق الفضائي (`#1E293B` / `#233054`) مع تأثيرات زجاجية ناعمة (`backdrop-blur`).
  * لون التمييز الأساسي: برتقالي ألعاب ناري مائل للذهبي (`#FF7A00` / `#F97316`).
  * حدود وتوهج العناصر: برتقالي متوهج (`glow effect`) للأزرار النشطة والتنبيهات.
* **الوضع الفاتح (Light Mode):**
  * خلفية لؤلؤية فاتحة مريحة للعين (`#F8FAFC`).
  * بطاقات بيضاء ناصعة بإطارات كحلية أنيقة وأزرار برتقالية واضحة.
* **الزخارف الإسلامية (Islamic Geometry):**
  * زخارف إسلامية هندسية مدمجة كخلفيات مائية ناعمة بتقنية SVG لتعطي فخامة إسلامية دون تشويش بصري.

## 4. بنية الصفحات والشاشات والتفاعلات الجديدة

### 1. شاشة اليوم الرئيسية (Daily Quest Dashboard):
* بطاقات الصلوات الخمس مع تبديل سريع:
  * مفتاح `Toggle`: «أدركت تكبيرة الإحرام».
  * مفتاح `Toggle`: «صُليت في المسجد».
  * عدّاد الركعات المدركة والفائتة.
* قسم النوافل اليومية بأزرار إنجاز سريعة.
* شريط المستوى والنقاط اليومية والشارات التنافسية (`Streak & Level`).

### 2. شاشة التقويم الشهري والقائمة الجانبية المنزلقة (Monthly Calendar & Side Drawer):
* **عرض التقويم:** شبكة كلاسيكية بالأيام (1 إلى 30 أو 31).
* **قفل الأيام المستقبلية (Future Days Restriction):**
  * أي يوم بعد اليوم الحالي يكون مقفلاً وغير قابل للضغط (`Disabled / Inactive`) ولا يمكن تسجيل صلوات له مسبقاً.
* **القائمة الجانبية المنزلقة (Side Drawer):**
  * عند النقر على أي يوم ماضٍ أو اليوم الحالي، تنزلق قائمة جانبية فاخرة (`Side Drawer / Sheet`) من جانب الشاشة (بدلاً من الـ Modal التقليدي).
  * تعرض تفاصيل كل صلاة من صلوات ذلك اليوم، النقاط المكتسبة، الركعات الفائتة، والنوافل.
  * تحتوي على زر «تعديل صلوات هذا اليوم» للتبديل الفوري لنمط التعديل والحفظ في `IndexedDB`.

### 3. شاشة تحليل الركعات الفائتة (Missed Rak'ahs Analytics):
* إجمالي الصلوات والركعات الفائتة في الشهر.
* تفصيل الركعات الفائتة لكل صلاة (فجر، ظهر، عصر، مغرب، عشاء).
* **فلتر الأيام الفائتة فقط:** جدول تفصيلي يظهر **حصراً الأيام التي ضاعت فيها ركعات** (مثال: `1/11: الظهر (ضاعت ركعتان) - العصر (ضاعت ركعة)`).

### 4. شاشة صلوات المسجد والنوافل (Mosque & Sunnah Attendance):
* إحصائية الصلوات المفروضة التي صُلّيت خارج المسجد.
* إحصائية النوافل المتروكة ونسبة الالتزام بالسنن.

### 5. شاشة السجل العام والتصدير (Monthly Matrix & Export Studio):
* مصفوفة شهرية كاملة حتى اليوم الحالي:
  * علامة صح خضراء (`✓`) إذا صُلّيت كاملة في المسجد.
  * رقم الركعات الفائتة بخلفية برتقالية/حمراء إذا ضاعت ركعات.
* أدوات التصدير الفوري:
  * تصدير التقرير كصورة عالية الدقة (`PNG`).
  * تصدير التقرير كملف `PDF` منظم للطباعة والمشاركة.
  * تصدير واستيراد قاعدة البيانات (`JSON Backup / SQLite Ready`).

---

## 5. معمارية التخزين (IndexedDB) والبناء للنشر
* **محرك التخزين:** استخدام `IndexedDB` لحفظ البيانات بشكل دائم وسلس على جهاز المستخدم داخل المتصفح، بدون حدود الـ LocalStorage.
* **التصدير للنشر على GitHub Pages:**
  * كود التطبيق في React + Vite.
  * تشغيل أمر `npm run build` لإنتاج مجلد `dist` الثابت الجاهز للنشر المباشر.
  * إعداد مسار نسبي (`base: './'`) في `vite.config.js` لضمان عمل الروابط والأصول على `GitHub Pages`.
